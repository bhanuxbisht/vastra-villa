# Vastra Villa - E-Commerce Web Application

A premium, highly responsive, and beautifully animated e-commerce website for a local shop ("Vastra Villa") specialized in Gen Z and aesthetic clothing for boys and girls (mainly students).

## Project Overview

- **Target Audience**: Gen Z students looking for aesthetic clothing.
- **Store Location**: Local shop ("near me" concept).
- **Core Focus**: 
  - Ultra-high speed and low-latency rendering of clothing catalogs.
  - Highly polished, premium visual design (rich aesthetics, modern typography, HSL-tailored colors, smooth gradients, subtle micro-animations).
  - Search Engine Optimization (SEO) friendly to maximize local discoverability.
  - Full responsiveness (mobile-first, since students access it on smartphones).

## Project Phases

### Phase 1: Core E-Commerce Catalog & Premium Front-End (Current Phase)
- **Technology Stack**: Next.js (App Router, TypeScript, Vanilla CSS Modules).
- **Aesthetics & UI/UX**:
  - Dark/Light mode support with HSL/OKLCH color system.
  - Custom scrollbars, fluid typography, and container-query layouts.
  - Smooth page and content transitions using CSS animations and native APIs.
- **Performance & SEO**:
  - Next.js Metadata API for robust SEO (title, description, OpenGraph, schema markup).
  - Image Optimization (`next/image`) for fast rendering and low latency.
  - Semantic HTML structure.
- **Product Catalog**:
  - Filterable aesthetic clothes categories (Boys, Girls, Tees, Hoodies, Cargoes, Accessories).
  - Local store details (Location, Hours, "Near Me" map integration).
  - Cart management (Client-side persistence).

### Phase 2: Authentication & Real-Time Ordering (Future Phase)
- Integration of secure user authentication.
- Real-time order placement and booking system.
- Live database updates and notifications.
